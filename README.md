# VigorSearch

『モンスターハンターライズ：サンブレイク』の傀異錬金術用の非公式ツールです。

スキル抽選の結果を初期 State から計算します。観測したスキル名から初期 State を復元する機能もあります。

## 注意事項

- このツールのコードは作者が行なった調査を元に、Claudeを利用して作成しています。
- 本ツールはゲームの開発元・販売元とは一切関係ありません。

## 動作環境

- Windows 10 / 11 (64bit)
- 自己完結型のため .NET のインストールは不要です

## 機能

- **一覧表示**: 初期 State と開始位置・件数を指定して、スキル1/スキル2、各レベル、スロットを一覧にします。
- **検索**: 探索範囲の中で指定したスキル1/スキル2、レベル(Lv ≧ n)、スロットをもつ護石を探します。スキルは順不同でも検索できます。
- **State の復元**: 観測したスキル名を書いたテキストファイルから初期 State を復元します。

## 基本的な使い方

1. 初期 State の S0〜S3 を16進で入力します。
2. 「一覧表示」で指定した開始位置から結果を表示します。
3. 一覧の State 列をダブルクリックするとその行の開始 State が初期 State に設定されます。
4. 任意の護石を検索する場合は条件を指定して「検索」を押します。

## State の復元

### 覇気の場合
連続したスキル1の情報から復元を行います。
観測ファイルに観測したAランクのスキル名を1行に1つずつ書きます。

添付された `obs.txt`には既に覇気用の観測記録が書いてありますが、単なるサンプルなので自由に消してください。
Aランク以外のスキルが出た場合、復元には使えないのでその行にはスキル名以外の文字を入れておきます。行番号は数えられるので行を詰めないでください。

錬金の「覇気」を選択して「Stateを復元」を押すと選択した観測ファイルを読み、成功すれば S0〜S3 の欄に自動で値が入ります。
観測が少ないと復元できず、不足しているビット数が表示されます。

### 円環の場合
連続したスキル2の情報から復元を行います。指定するスキルのランクごとに異なる State が割り当てられているので注意してください。
観測ファイルに観測したAランクのスキル名を1行に1つずつ書きます。

添付された `obs2.txt`には既に円環用の観測記録が書いてありますが、単なるサンプルなので自由に消してください。
Aランク以外のスキルが出た場合、復元には使えないのでその行にはスキル名以外の文字を入れておきます。行番号は数えられるので行を詰めないでください。

指定したスキル1がAランクの場合、まずは「攻撃」を指定します。
十分記録した後は再抽選を考慮するためゲームをセーブせずリセットし、「挑戦者」指定でやり直します。そして、「攻撃」選択時と比較してスキル2の結果に不一致がないか確認します。
具体的には、「挑戦者」選択時に攻撃を引いたら「攻撃」選択時に再抽選が発生していたことが分かるので記録の該当箇所を「攻撃」に修正します。
SBCをスキル1に指定している場合は再抽選を考慮しなくていいのでこの作業は不要です。

錬金の「円環」を選択して「Stateを復元」を押すと選択した観測ファイルを読み、成功すれば S0〜S3 の欄に自動で値が入ります。
観測が少ないと復元できず、不足しているビット数が表示されます。

## 既知の問題・未検証の事項

### 未検証の事項
- v1.1.3で円環の不具合を修正しましたが、コード内の HeadMode(1 or 2) と LastMode(3 or 4) の正しい設定がどちらなのかは未検証です。現在は前者を2、後者を4に設定しています。この問題は円環でスキル1に HeadSkills か LastSkills を指定した際に稀に影響するだけで、覇気は無関係です。

### ゲーム側の問題
- 重み抽選のテーブルにオフバイワンエラーが生じており、開発時のミスと思われます。 ツール内で HeadSkills と LastSkills が抽選された時の処理が複雑なのはそのためです。
