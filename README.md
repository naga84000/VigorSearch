# VigorSearch

『モンスターハンターライズ：サンブレイク』の傀異錬金術用の非公式ツールです。

スキル抽選の結果を初期 State から計算します。観測したスキル名から初期 State を復元する機能もあります。

## 注意事項

- このツールのコードはClaudeを利用して作成しています。
- 本ツールはゲームの開発元・販売元とは一切関係ありません。
- 本ツールで行うことはゲーム内で観測した結果をもとにした計算です。ゲームに接続したり、ゲームのファイルやメモリを書き換えたりはしません。
- オンラインで他のプレイヤーに迷惑をかける使い方はお控えください。
- 本ツールの利用により生じた損害について作者は責任を負いません。

## 動作環境

- Windows 10 / 11 (64bit)
- 自己完結型のため .NET のインストールは不要です

## 機能

- **一覧表示**: 初期 State と開始位置・件数を指定して、スキル1/スキル2、各レベル、スロットを一覧にします。
- **検索**: 探索範囲の中で指定したスキル1/スキル2、レベル(Lv ≧ n)、スロットをもつ護石を探します。スキル1/2は順不同でも検索できます。
- **State の復元**: 観測したスキル名を書いたテキストファイルから初期 State を復元します。

## 基本的な使い方

1. 初期 State の S0〜S3 を16進で入力します。
2. 「一覧表示」で指定した開始位置から結果を表示します。
3. 一覧の State 列をダブルクリックするとその行の開始 State が初期 State に設定されます。
4. 任意の護石を検索する場合は条件を指定して「検索」を押します。

## State の復元
### 覇気の場合
連続した第一スキルの情報から復元を行います。
観測ファイル(既定は `obs.txt`)に観測したAランクのスキル名を1行に1つずつ書きます。

添付された `obs.txt`には既に観測記録が書いてありますが、単なるサンプルなので消してください。
Aランク以外のスキルが出た場合、復元には使えないのでその行にはスキル名以外の文字を入れておきます。行番号は数えられるので行を詰めないでください。

錬金の「覇気」を選択して「Stateを復元」を押すと exe と同じフォルダ(なければカレントフォルダ)のファイルを読み、成功すれば S0〜S3 の欄に自動で値が入ります。
観測が少ないと復元できず、不足しているビット数が表示されます。

### 円環の場合
連続した第二スキルの情報から復元を行います。指定するスキルのランクごとに異なる State が割り当てられているので注意してください。
観測ファイル(既定は `obs2.txt`)に観測したAランクのスキル名を1行に1つずつ書きます。
添付された `obs2.txt`には既に観測記録が書いてありますが、単なるサンプルなので消してください。

Aランク以外のスキルが出た場合、復元には使えないのでその行にはスキル名以外の文字を入れておきます。行番号は数えられるので行を詰めないでください。
指定スキルがAランクの場合、復元に必要な分記録した後ゲームを一旦リセットします。そして別スキル指定でまた錬金を行い再確認してください(再計算を考慮するため)。

錬金の「円環」を選択して「Stateを復元」を押すと exe と同じフォルダ(なければカレントフォルダ)のファイルを読み、成功すれば S0〜S3 の欄に自動で値が入ります。
観測が少ないと復元できず、不足しているビット数が表示されます。
